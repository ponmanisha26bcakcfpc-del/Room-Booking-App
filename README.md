# 🏨 Room Booking App UI Design – High-Fidelity

## ✨ Project Overview

This is a **Room Booking App High-Fidelity UI Design** created using Figma. The application provides a modern and attractive interface for users to explore hotels, view room details, check room availability, book rooms, make payments, and manage their reservations.

## 🎯 Objective

The main objective of this project is to design a **user-friendly Room Booking application** with a clean, modern, and visually appealing interface that makes finding and booking hotel rooms easy, quick, and convenient.
